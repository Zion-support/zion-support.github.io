# Zion i18n (static pages)

Languages live now: **PT-BR** and **EN**. Add ES later as a third column in the map — do not ship empty `/es/` shells.

## Future page (required)

1. Set language and twins on the root tag:

```html
<html lang="pt-BR" data-i18n-pt="/minha-pagina/" data-i18n-en="/en/minha-pagina/">
```

2. Include the engine once:

```html
<script src="/assets/js/i18n.js" defer></script>
```

3. Add one row to `assets/data/lang-map.json` **and** `public/assets/data/lang-map.json`.

4. Dual-write HTML to repo root **and** `public/`.

## Rules

- No Accept-Language auto-redirect (SEO).
- Unmapped path: switcher stays on the same URL.
- Official menu only: Discovery $99 · Consulting $499 · Starter $2,500 · Growth $8,000/mo.
- `zion-shell.js` and `zion-catalog.js` load `i18n.js` automatically.
