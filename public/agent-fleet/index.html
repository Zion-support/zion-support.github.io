Agent Fleet

A fleet is a list of agents with owners, tools, and a way to turn each one off. This page writes that list. It does not deploy an agent.

Keep with every agent

  • One owner who can stop it the same day.
  • The tools it may call, written down.
  • A human check before it changes a customer, a payment, or a control.
