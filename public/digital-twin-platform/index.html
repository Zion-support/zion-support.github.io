System map notes

Product pages call this a digital twin. Here it is a list you type. Nothing is modeled, simulated, or connected.

Write down

  • The system name, where it runs, and who can change it.
  • What it depends on, and what depends on it.
  • The last time someone checked that the description is still true.

A list is not a live twin and not an architecture diagram generator.
