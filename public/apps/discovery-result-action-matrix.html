3. Apply three gates before a paid implementation

Baseline

Write the current volume, time, cost or error signal. If you cannot measure the baseline, start there.

Owner

Name the person who can grant access, approve the test and accept or reject the outcome.

Stop rule

Define when the experiment should stop because value, safety or operational fit is not good enough.
