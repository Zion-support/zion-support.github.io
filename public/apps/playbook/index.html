How to use the apps network

These tools live on GitHub Pages at ziontechgroup.com/apps/. They do not create SKUs. They help a buyer (or an agent) walk into Discovery with a number, a brief, or a score.

If the pain is money

  1. Open ROI calculator — hours × loaded rate vs the official menu.
  2. If the spend is model calls, open token cost.
  3. If the spend is cloud, open FinOps estimator, then cloud waste, then FinOps consulting.

If the pain is an outage

  1. Incident cost turns hours-down into a dollar figure.
  2. SLA calculator shows the contract allowance and penalty math.
  3. Change risk scores the next change before you book the window.
  4. Patch window sizes the next change night so the same outage does not repeat.
  5. Product path: AI Incident Commander · Ops Runbook AI.

If the pain is “we want an agent”

  1. Stack audit — ten gates. Under 5 → Discovery. 5–7 → Consulting. 8+ → Starter.
  2. AI governance — policy, HITL, PII, spend tracking.
  3. Agent brief + prompt library — paste into Discovery.
  4. Product path: LLM Gateway · Prompt Shield · AI Agent Builder.

If the pain is a public bid

  1. RFP readiness — score the packet before a week of writing.
  2. Edital desk — órgão, objeto, lacunas. Never invent hardware price.
  3. Product path: Licitação Radar · AI Tender Scout.
  4. Then Discovery $99 or contact.

Official menu only: Discovery $99 · Consulting $499 · Starter $2,500 · Growth $8,000/mo.
