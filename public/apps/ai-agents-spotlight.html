AI agents and automation

Desks for agents and workflows that open on this site. Older hostnames for fleets, swarms, and orchestrators do not open. Nothing here is deployed from the page.

Desks that open

  • Agent builder desk — The brief for one agent.
  • AgentForge — Design notes that stay on this site.
  • Agent fleet — The roster a person already named.
  • Agent directory — Links to those desks. No rating and no payment.
  • Swarm roster — Who is in the group.
  • Swarm review — What a person reads before a run.
  • Workflow desk — The steps, written down.
  • Automation sketch — A sketch, not a running job.
  • Workflow builder — The builder page that stays on this domain.
  • Orchestration map — Which desk follows which.
  • Voice script desk — The words for a call. No call is placed.
  • Incident commander desk — Severity and the sentence a person posts. No paging.
  • Evals studio — The questions. No model call.
  • Eval notes — What good looks like, in words.
  • Model observatory desk — What you would watch. No trace is pulled.
  • Dispatch orchestrator — Scheduling notes on this site.
  • Autonomous agents — The service page.
  • Status note — The customer update. No uptime number.
