A written-first evaluation plan

  1. Name the process owner and the current workflow.
  2. Select three fictional or fully anonymized cases and write the expected category, priority and escalation.
  3. Measure current handling time before testing. Record actual results, not advertised percentages.
  4. Review each proposed answer with a human. Keep the trial separate from live customer communications.
  5. Record misses and stop if sensitive information, unsupported claims or unsafe actions appear.
  6. Decide build, revise, wait or do-not-build in writing. Schedule a meeting only if needed or requested.
