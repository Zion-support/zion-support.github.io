Secret notes

The older Secrets Sentinel page still shows broken styles and asks you to paste a config. Use this note instead. Do not type a key, token, or password here.

Write down

  • The system name, not the secret.
  • Where the config lives: a repo name or a host name.
  • The person who rotates it, and the date.
  • Who to tell if it was copied into a ticket.


A filled note is a reminder for a person. It is not a scan result and not proof that a repository is clean.
