Data ops notes

Six written notes for the September 24 data list. Nothing here is scanned, scored, cataloged, or sent. A person writes the facts.

The six notes

  • Data catalog. Write the table name, the owner, and where the row came from. This page does not read a warehouse.
  • Pipeline monitor. Write which job failed and who will look at it. Nothing is restarted from here.
  • Quality watchdog. Write the column, the rule, and the date a person checked it. Related: data quality notes.
  • Metric notes. Write the metric, the usual range, and who should read it. No alert is sent.
  • Dashboard notes. Write the chart name and the sentence a person would say about it. Nothing is generated.
  • Report notes. Write who should receive the report and when a person will send it. This page does not deliver mail.
