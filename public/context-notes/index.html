Context notes

Write the job and the text you already have before anyone counts tokens or builds stand-in rows. Nothing here is generated, scored, or sent.

Write these down

  • The job the text is for, and the length you already have in hand.
  • The model name as it appears on the invoice, not a pasted hostname.
  • Whether a real customer row would be copied into a sample. If yes, stop.
  • Who is allowed to read a sample, and when that file is deleted.
