Swarm roster

A swarm is a short list of agents that pass work to each other. This page writes that list. It does not start an agent.

Write down

  • One owner for the whole group.
  • The handoff: what the next agent is allowed to receive.
  • A stop that the owner can use the same day.


Do not give the group a tool that moves money or changes access until the owner has tried the stop.
