What “installed” means

Installed means the agent can complete the named workflow with a short list of tools, stop or escalate when policy says so, and leave a trail. It does not mean a widget that answers FAQ. The production minimum matches the five-point checklist on autonomous AI agents.

  1. Named owner — a person who can pause the agent and change the allowlist.
  2. Allowed tools only — CRM, ITSM, email, Slack, WhatsApp, or internal APIs you approve. No runtime invention of new integrations.
  3. Human approval — irreversible or high-cost actions wait for a person.
  4. Audit log — tool calls, inputs, and outcomes are written down.
  5. Kill switch & rollback — disable the agent without taking the rest of the stack down.

What is not in an install

Usage invoices

Model tokens, embeddings, and cloud spend stay on your vendor bills. Pair with FinOps if that line is already the constraint.

Unbounded autonomy

We will not install an agent that closes tickets, moves money, or changes access without a stop rule.

A second process you have not named

Sprint and Production are one workflow. Fleet is three named ones — not “whatever comes next.”
