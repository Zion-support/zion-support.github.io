FAQ

Can you configure a third-party agent platform?

Yes, if we can set allowlists, gates, and a kill switch on that platform. If the vendor will not expose those controls, we will say so in the first working session and refund is not automatic — write us before you pay if the stack is exotic.

Do we need Governance Config or just Config Sprint?

Config Sprint is enough when the owner is already named and the risk is operational. Governance Config is for a control owner who needs a pack and a readout. Do not buy both on the same agent in the same week — Governance includes Sprint.
