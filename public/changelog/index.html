Changelog notes

Older product pages link this address as a changelog. Write the release here. This page does not read a repository or post a note for you.

Write down

  • The date, and the name a customer would recognize.
  • What changed, in one sentence, and who should know.
  • What did not ship, so the next note does not repeat it.

A changelog entry is not a status board and not an uptime claim.
