App-KatalogNetzwerkkarte

Bestimmen Sie die Art der Ressource

Lokales Browserwerkzeug

Ein Rechner, regelbasierter Textgenerator oder eine Checkliste kann im Browser funktionieren. Reproduzieren Sie das angegebene Ergebnis und prüfen Sie die Grenzen; KI im Namen beweist keine Modellanbindung.

Manueller Leitfaden oder Prototyp

Ein Leitfaden unterstützt eine Person beim Planen oder Prüfen. Ein Prototyp kann unfertige Funktionen enthalten. Prüfen Sie, welche Aktionen implementiert sind und welche eine Person erfordern.

Angebundene Integration

Bestätigen Sie die tatsächliche Dienstanbindung, den Datenfluss, die Berechtigungen und die getestete Version. Eine veröffentlichte Seite oder ein Code-Repository allein beweist keine funktionierende Integration.

Fünf Prüfungen für einen nützlichen Pilotversuch

  1. Aufgabe festlegen

    Benennen Sie die Prozessverantwortlichen, den Ausgangswert und ein messbares Erfolgskriterium. Halten Sie den ersten Versuch klein und umkehrbar.

  2. Eingaben prüfen

    Beginnen Sie mit erfundenen Beispielen oder bereinigten und freigegebenen Daten. Prüfen Sie Datenverarbeitung und Abhängigkeiten vor der Eingabe von Geschäftsunterlagen; verwenden Sie keine Zugangsdaten oder privaten Kundendaten in öffentlichen Werkzeugen.

  3. Ergebnis reproduzieren

    Vergleichen Sie die Ausgabe mit dem erwarteten Ergebnis. Testen Sie leere oder ungültige Eingaben, prüfen Sie Fehlermeldungen und das Verhalten nach einer Änderung von Annahmen.

  4. Menschliche Entscheidung prüfen

    Bestimmen Sie, wer die Ausgabe prüft und wer den Versuch genehmigen, stoppen oder rückgängig machen darf. Ein Entwurf, Szenario oder eine Checkliste erlaubt weder Versand noch Kauf oder Einsatz.

  5. Nachweise festhalten

    Dokumentieren Sie die genaue URL oder Version, das Beispiel, das beobachtete Ergebnis, die Grenzen und die Prüfentscheidung. Kennzeichnen Sie ungeprüfte Funktionen ausdrücklich als nicht getestet.

Prüfbeispiel: Besprechungsnotizen

Verwenden Sie erfundene Notizen mit einer Entscheidung, einer verantwortlichen Person und einer Frist. Vergleichen Sie den Entwurf mit diesen drei Angaben und wiederholen Sie den Test ohne Frist. Ein nützliches Ergebnis muss die fehlende Frist sichtbar machen, statt eine zu erfinden. Eine Person prüft den fertigen Text vor der Weitergabe.
