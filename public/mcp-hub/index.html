MCP hub

An MCP server is a tool an assistant can call: search a folder, open a ticket, read a calendar. Before you connect one, write the name, the owner, and the data it can read. This page does not install a server and does not ask for a key.

Name

What a person will see in the tool list. Avoid a name that sounds like a different system.

Owner

The person who can turn the tool off. A shared inbox with no name is not an owner.

Data

The records the tool can read or change. If the list is “everything,” it is not ready.

A starter file layout is on the MCP server scaffold. Score the result in Evals studio after you have a real task, not a demo prompt.
