Micro-SaaS notes

The stack recommender still links this address as a studio. List the user, the one job the screen does, and how a person cancels. No account is created here.

Scope

  • Who the user is, and the job they already do without the product.
  • The one action the first screen must finish.
  • What is stored, where, and how a person deletes it.
  • How billing stops, and who receives that request.

Out of scope for the first build

A second user role, a marketplace, and any number you have not measured.
