Voice script desk

The older Voice Agent Studio page still shows broken styles. Use this desk. It does not dial a number and it does not generate a voice.

Write down

  • Who may hear the script.
  • The words, in plain language.
  • How a person stops or refuses the call.
  • Where consent was recorded, if a call is allowed at all.


If you do not have consent, leave the words blank and talk to counsel before any outbound call.
