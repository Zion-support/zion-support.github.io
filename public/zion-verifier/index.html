Prompt check notes

The scanner still links this address as a verifier. A person reads the draft before it is used. This page does not scan a prompt and does not store one.

Read for these four things

  • No keys, tokens, or passwords in the text.
  • No customer rows, and no file path from a private system.
  • A stop rule a colleague can point to, and an owner.
  • A place the approved copy will live that is not this website.
