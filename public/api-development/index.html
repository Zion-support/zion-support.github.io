API notes

The API guardian links this address. Write the contract before a route exists. This page does not generate code or issue a key.

Decide first

  • Who calls it, and what they are allowed to change.
  • The fields that must stay stable, and the ones that may change.
  • How a caller learns that a field was removed.
  • Where the log lives, and who can read it.
