Swarm review

Version two of a swarm adds a reviewer. This page names that person and the rule they use. It does not run a consensus algorithm.

Write down

  • A person, not another agent, reads the output.
  • What they reject.
  • Where the rejected work goes.


If nobody is named, the swarm does not send the output.
