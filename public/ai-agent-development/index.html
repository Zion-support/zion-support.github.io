Agent development notes

The handoff designer still links this address. Write the job, the stop rule, and the person who accepts the output. This page does not call a model.

Write before anyone builds

  • The job, in one sentence a colleague can repeat.
  • The inputs the agent may see, and the inputs it must not see.
  • The stop rule: when a person takes the work back.
  • The person who accepts the output, by name.
