# Zion App Network Spotlight — Batch 51: Data Engineering & Observability (Sep 26, 2026)

Eight interlinked apps for the modern data stack: **build → catalog → trust → serve → optimize**.

- **[Zion Data Pipeline Hub](https://ziontechgroup.com/zion-data-pipeline-hub/)** — Visual data pipeline builder — design, run and monitor ETL/ELT pipelines with connectors, scheduling and lineage. ([repo](https://github.com/Zion-support/zion-data-pipeline-hub))
- **[ETL Copilot AI](https://ziontechgroup.com/etl-copilot-ai/)** — AI copilot that generates, documents and refactors ETL jobs from natural language. ([repo](https://github.com/Zion-support/etl-copilot-ai))
- **[Data Quality Guard](https://ziontechgroup.com/data-quality-guard/)** — Continuous data quality monitoring — anomaly detection, schema drift alerts and freshness checks. ([repo](https://github.com/Zion-support/data-quality-guard))

- **[Warehouse Optimizer AI](https://ziontechgroup.com/warehouse-optimizer-ai/)** — Cloud data warehouse cost & performance optimizer for Snowflake, BigQuery and Redshift. ([repo](https://github.com/Zion-support/warehouse-optimizer-ai))
- **[Data Catalog AI](https://ziontechgroup.com/data-catalog-ai/)** — AI-powered data catalog with automated lineage, glossary and discovery search. ([repo](https://github.com/Zion-support/data-catalog-ai))
