## 6. RECOVERY PROCEDURES

### If All Email Connections Expired
1. Check portal.nousresearch.com for reconnect options
2. Contact admin@ziontechgroup.com for API keys
3. Use SMTP relay as fallback (see tools/email-smtp.md)
4. Document lost opportunities in Notion

### If Website Returns 404s
1. Check if page.tsx exists in app/{path}/
2. Create static HTML if needed in public/{path}/index.html
3. Commit and push to main
4. Trigger: `gh workflow run static-deploy.yml --ref main`

### If Build Fails
1. Run: `npm run type-check` first
2. Check for missing dependencies: `npm install`
3. Look for circular imports in app/data/
4. Review CI logs: `gh run view --log`
