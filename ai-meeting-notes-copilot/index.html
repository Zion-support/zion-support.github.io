Organize pasted notes using explicit keyword rules. This is not audio transcription, semantic AI or a Notion integration. Review every extracted line.

Recap

First steps
  1. Use fictional or sanitized inputs; do not paste credentials, private client data or confidential transcripts.
  2. Check facts, recipients, owners and deadlines before manually sharing any output.
  3. Define the baseline, accountable owner, approval gate and rollback plan before a separately authorized pilot.
Capabilities and limits
Local rules can miss or misclassify information. No model, account connection, upload, server storage or automatic action is implemented by these tools. Clipboard copying occurs only when requested.
Discovery is a separate scoping request, not a purchase or dispatch. Email delivery and inbox receipt are not guaranteed by these pages.
