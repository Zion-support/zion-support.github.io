Agent directory

The older marketplace page promised ratings and payments. This page does not rate an agent, list a price, or take a payment. It points at the desks that open.

Desks that open

  • AgentForge — the design notes that stay on this site.
  • Agent fleet — the roster of agents a person already named.
  • Swarm roster and swarm review — who is in the group, and what a person will read before a run.
  • Workflow desk and automation sketch — the steps, written down.
  • Evals studio and eval notes — the questions, not a score from a model.
  • Orchestration map — which desk follows which.
