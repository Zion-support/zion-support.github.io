Hermes agent notes

An operations agent records what a person already decided. This page does not page anyone and does not change a system.

What to write down

  • The decision a person made, and the date they made it.
  • Which system the note describes. The agent does not log into it from this page.
  • Who is allowed to act when the note says something failed.
  • The wider agent scope lives on autonomous agents. A price is on the published plans.
