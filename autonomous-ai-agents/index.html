Five Production Controls

  1. Named owner — human who can pause and change tool list
  2. Allowed tools only — no runtime integration invention
  3. Human approval — irreversible actions wait for a person
  4. Audit log — tool calls, inputs, outcomes written down
  5. Kill switch & rollback — disable without stack impact
